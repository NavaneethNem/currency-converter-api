# Currency Converter API
A beginner Python project for learning REST APIs

## Features
- Currency conversion using CurrencyLayer API
- API key authentication
- Enviornment variables for API credentials
- Error handling
- User input validation

## Setup
Configure API Key
Create a .env file:
CURRENCYLAYER_API_KEY=your_api_key_here
Run
python Currency_Converter.py

### Install dependencies
```bash
pip install -r requirements.txt
